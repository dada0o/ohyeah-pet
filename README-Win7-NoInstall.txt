小欧公爵和小耶牧师桌宠 - Windows 7 免安装版
================================================

这个版本不需要安装 .NET Framework 4.8，也不需要运行安装程序。

适用系统
--------
- Windows 7 SP1，32 位或 64 位。
- 程序使用 Windows 7 自带的 .NET Framework 3.5.1。

使用方法
--------
1. 完整解压 ZIP，不能直接在压缩包预览窗口中运行。
2. 保留 EXE 和同名的 EXE.config 文件在同一个文件夹。
3. 双击“小欧公爵和小耶牧师桌宠-Win7免安装版.exe”。

开机自动启动
------------
- 第一次运行后默认开启开机自动启动。
- 可从桌宠右键菜单或任务栏托盘菜单取消、重新勾选。
- 手动关闭后程序会记住选择，不会在下次运行时自行恢复。

如果系统提示需要启用 .NET Framework 3.5.1
------------------------------------------
少数精简系统可能关闭了 Windows 自带组件。打开：
控制面板 -> 程序和功能 -> 打开或关闭 Windows 功能，勾选
“.NET Framework 3.5.1”，确定后重启。无需安装 .NET Framework 4.8。

功能说明
--------
- 单击桌宠：摸摸。
- 按住拖动：移动位置。
- 右键：互动、活动范围、自由动作、自动启动、大小和退出。
- 任务栏右下角托盘图标：叫回桌面或退出。
- Win7 版使用较低动画帧率和轻量特效，减少老电脑负载。

安全说明
--------
- 桌宠目前没有商业代码签名证书，部分安全软件可能对微信自动接收的
  未签名 EXE 产生误报。
- 不要关闭安全软件，也不要从不明来源下载。
- SHA256SUMS.txt 列出了文件校验值，可用于确认传输后文件没有被改动。
