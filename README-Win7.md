# Windows 7 兼容版

此版本适用于 Windows 7 SP1，支持 32 位和 64 位系统。

## 使用方法

1. 完整解压 ZIP，不能直接在压缩包预览窗口中运行。
2. 保留 EXE 和同名的 EXE.config 文件在同一个文件夹。
3. 双击“小欧公爵和小耶牧师桌宠-Win7兼容版.exe”。

## 系统要求

- Windows 7 SP1。
- .NET Framework 4.8；如果系统没有安装，需要先从微软官方渠道安装。

## 开机自动启动

第一次运行后默认开启。右键任意桌宠，或打开任务栏通知区域的桌宠菜单，可以取消或重新勾选“开机自动启动”。手动关闭后程序会记住选择。

## 安全说明

当前发布包没有商业代码签名证书。请只从项目的 GitHub Release 或可信的本地目录运行，不要关闭安全软件。
