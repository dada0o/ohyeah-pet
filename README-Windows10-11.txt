小欧公爵和小耶牧师桌宠 Windows 10/11 版
============================================

推荐使用安装版：
1. 双击 PetFriends-v{VERSION}-Windows10-11-x64.exe。
2. 按提示完成安装，安装后会自动启动。
3. 桌面和开始菜单都会提供快捷方式。

便携版：
1. 必须完整解压 PetFriends-v{VERSION}-Windows10-11-x64-Portable.zip。
2. 进入解压后的文件夹。
3. 双击“小欧公爵和小耶牧师桌宠.exe”。
4. 不要把 EXE 单独移出文件夹，旁边的 DLL 都是运行所需文件。

本版本自带 .NET 运行环境，不需要安装 .NET 或 VC++ 运行库。
如果启动失败，请把以下日志发给开发者：
%LOCALAPPDATA%\PetFriends\runtime.log
