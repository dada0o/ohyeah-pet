小欧公爵和小耶牧师 · Windows 桌宠

使用方法
1. 双击“小欧公爵和小耶牧师桌宠.exe”。
2. 单击角色：立即摸摸它，会跳一下、说话并冒爱心。
3. 按住角色拖动：可把两只分别放到桌面的任意位置。
4. 把两只拖近：松手后它们会马上聊天、冒爱心，或触发贴贴动作。
5. 右键任意角色：可立即贴贴、喂零食、调整大小、开启安静模式或退出。
6. 右下角托盘也有入口；双击托盘图标可把走丢的桌宠叫回来。

双宠互动
- 把它们拖近会随机触发：亲脸颊、碰碰鼻子、蹭蹭脸、牵爪、说悄悄话、整理毛发、互相夸奖、贴贴、击掌、同步跳舞、追逐、分享点心、安慰、打盹或聊天。
- 右键任意角色，打开“互动小游戏”，可以直接选择想看的互动。
- 两只即使暂时分开，也会每隔约 10–18 秒主动跑向对方并互动，不需要一直手动拖近。

自由活动
- 默认使用“专注陪伴”：把任意一只拖到想放的位置并松手，该位置就会成为新的活动区中心；两只只在附近约 580×380 像素的小区域内活动。
- 活动区靠近屏幕边缘时会自动收进屏幕；另一只如果离新区域太远，会自己跑过来，不会瞬移。
- 专注模式只限制自动待机范围，不限制手动操作；右键选择跑动、屏幕探头、窗口探头、坐窗口以及所有双宠互动时都会完整执行，结束后再返回专注区域。
- 右键“活动范围”可切换到“全屏撒欢”：它们会斜着跑、上下移动，并在桌面不同位置追逐。
- 全屏撒欢时，它们偶尔会一起藏到屏幕左右边缘并歪头探出：小欧固定在上、小耶固定在下。角色图片始终完整，只是身体移到屏幕外，脸和两只前爪自然留在屏幕内。
- 全屏撒欢时，它们会识别当前打开的普通窗口，跳到窗口上沿坐一会儿。
- 它们会优先选择你最近正在使用的浏览器或应用窗口；普通窗口会坐在外框上沿，最大化网页会坐在浏览器内部上沿。
- 全屏撒欢时还会偶尔躲到应用窗口后面，并使用 Windows 的真实可见边框和 DPI 比例定位。
- “窗口边缘探头”由两只桌宠一起行动：小欧固定在上、小耶固定在下，并根据当前窗口左右两侧的空间选择更合适的边缘。它们在左边缘会逆时针歪头，在右边缘会顺时针歪头。
- 探头时不裁切图片：完整桌宠位于当前应用窗口后层，大部分由应用窗口自然遮挡，只让越过左侧或右侧边框的脸和小爪子露出来；窗口贴住屏幕边缘或最大化时，改由屏幕边界自然遮挡。
- 右键“自由活动动作”可以手动选择“坐到当前窗口上面”或“躲到当前窗口后面”；托盘菜单也能切换两种模式。

小提示
- 桌宠会保持在其他窗口上方。
- Windows 10/11 使用同一个版本；Windows 11 会自动启用兼容渲染模式。
- 当前默认大小相当于旧版的“小小只”；右键仍可选择迷你、默认或大一点。
- 安静模式下不会随机走动和说话，手动摸摸/贴贴仍然有效。
- 若 Windows 首次启动时显示安全提示，请确认文件来自你自己的桌宠文件夹后选择运行。
